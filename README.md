# ByteXL Lab Experiments

A curated collection of practical lab experiments, practice tasks, and backend/frontend implementations completed during the **5th Semester of B.Tech** as part of the ByteXL curriculum.

---

## 📌 Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), React.js (`.jsx`)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication & DevOps:** JWT (JSON Web Tokens), YAML configuration
